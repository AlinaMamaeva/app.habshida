## 🛠 Running Locally

1. Clone the repository
```bash
git clone https://github.com/AlinaMamaeva/app.habshida.git
```

2. Navigate to the project folder
```bash
cd app.habshida
```

3. Install dependencies
```bash
npm install
```

4. Run the development server
```bash
npm run dev
```

5. Open in browser: http://localhost:5173
